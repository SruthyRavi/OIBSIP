# Temperature Converter

A simple, responsive temperature converter built using HTML, CSS, and Vanilla JavaScript as part of the Oasis Infobyte Web Development and Design Internship (OIBSIP), Level 1.

## Features

- Enter a temperature value.
- Select Celsius, Fahrenheit, or Kelvin as the input unit.
- Convert the temperature into all three units simultaneously.
- Display results with accurate unit labels.
- Validate empty and invalid inputs.
- Handle absolute-zero violations with user-friendly error messages.
- Responsive and clean user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Conversion Formulas

- Celsius to Fahrenheit: `(C × 9/5) + 32`
- Fahrenheit to Celsius: `(F − 32) × 5/9`
- Celsius to Kelvin: `C + 273.15`
- Kelvin to Celsius: `K − 273.15`

## How to Run

1. Clone or download this repository.
2. Open the `WebDev-L1-TemperatureConverter` folder.
3. Open `index.html` in your web browser.
4. Enter a temperature, select its unit, and click Convert Temperature.
