# Glowora – Skincare Landing Page

## Overview
Glowora is a fictional premium skincare brand landing page created as part of the Oasis Infobyte Web Development and Design Internship – Level 1, Task 1.

The website presents a clean, elegant, and responsive design to introduce skincare products and the brand's philosophy.

## Technologies Used
- HTML5
- CSS3

## Features
- Responsive navigation bar
- Hero section with call-to-action
- About section
- Brand features section
- Product showcase
- Customer testimonials (sample content)
- Contact section
- Footer with social links
- Responsive layout for mobile devices

## Project Structure
```text
WebDev-L1-LandingPage/
├── index.html
├── style.css
├── README.md
└── assets/
    └── images/
```

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a browser.

## Note
Glowora is a fictional brand created for educational and internship purposes. Product details, testimonials, and contact information are sample content.
